# Границы первой версии

Это работающая основа для тестирования одного приложения. Она не объявляется готовым коммерческим каталогом до сквозного теста с Telegram и тестовой ЮKassa.

## Проверенная доставка

Исходная проба на двух iPhone показала: оригинальный Happ устанавливается через HTTPS-страницу и `itms-services`. На втором устройстве потребовался вход в App Store под аккаунтом, которым получен файл; после выхода приложение продолжило работать. Это наблюдение по этим устройствам, а не гарантия работы любого IPA, любой iOS или бессрочной активации.

Новый сервис повторяет способ доставки, но закрывает установочные ссылки проверенной оплатой и владельцем заказа. Сам IPA не публикуется в Git и не выдаётся без действующего разрешения.

## Что пока делается вручную

- Активация и получение кодов Apple: через поддержку. Автоматического получения 2FA нет.
- Сейчас хранится личный тестовый IPA владельца. Массовая раздача и использование личного Apple Account в коммерческом сервисе не подготовлены. Нужен отдельно выбранный способ получения приложений и предоставления доступа.
- Каталог содержит Happ. Добавление других приложений, версии/архивы и админка — следующие изменения, а не готовая универсальная загрузка любого IPA.
- Контакты продавца, оферта, правила возврата, право распространять конкретные приложения и параметры чеков определяются владельцем до приёма настоящих денег.
- Возврат денег оператор делает в кабинете ЮKassa; сервис отслеживает подтверждённый полный возврат и закрывает выдачу доступа. Частичные возвраты оставляют доступ.
- Отдельные пользовательские аккаунты Apple и их пароли сервис не собирает. Режим `credentials` предназначен только для специально выбранных владельцем реквизитов; по умолчанию выключен.

## Приёмочный тест после заполнения .env

1. Запустить бота и открыть каталог из его кнопки.
2. Создать один заказ в тестовом магазине и пройти hosted checkout с тестовыми данными ЮKassa.
3. Вернуться в заказ: статус меняется только по проверке API. Проверить уведомление и повторное уведомление.
4. Получить ссылку, открыть её в Safari на согласованном iPhone и проверить установку/активацию, предварительно сохранив настройки установленной копии.
5. Убедиться, что другой Telegram-пользователь не видит заказ; истёкшая ссылка не работает, а новую может получить владелец.
6. Выполнить тестовый полный возврат в кабинете; убедиться, что дальнейшая выдача закрыта.

Боевая ЮKassa не включается скриптом тестового развёртывания. При подключении настоящих оплат отдельно проверяются коммерческие условия, чеки и правила платформы. Для цифровых товаров Telegram документирует оплату Stars; здесь по выбору владельца реализован внешний checkout ЮKassa. Это технический выбор, не обещание одобрения со стороны Telegram.

Источники: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [Telegram Bot API](https://core.telegram.org/bots/api), [Telegram digital goods](https://core.telegram.org/bots/payments-stars), [ЮKassa](https://yookassa.ru/developers/payment-acceptance/integration-scenarios/manual-integration/basics).
